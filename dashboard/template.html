Method. DAU = COUNT(DISTINCT user_id) per day; a user may appear once per platform per day. Because distinct counts don't add up across platforms, the breakdowns show average daily DAU (additive) so every filter stays correct. Countries are additive (one country per account).

Local prototype. PostgreSQL → CSV, Elasticsearch → NDJSON, BigQuery → DuckDB (see dashboard/build_data.py). Regenerate with make sample-data && make run && make dashboard. In production the same dashboard reads fact_daily_user_activity in BigQuery (partitioned by day, clustered by country & platform).
